# 🔐 Offensive Networking — Fundamental Prerequisites for Pentesters & Bug Bounty Hunters

A structured and professional learning repository focused on the essential foundational topics required for **offensive security**, **penetration testing**, and **bug bounty hunting**.
This project provides concise, practical, and security-oriented explanations designed to help beginners build a strong base in the areas that matter most in real-world offensive operations.

---

## 🎯 **Core Learning Areas**

Below are the six primary domains covered in this repository—each introduced with a short explanation, followed by a direct link to the corresponding material.

---

### 🧩 **1. Networking Fundamentals**

Essential networking concepts required for reconnaissance, enumeration, bypassing defensive layers, and exploiting misconfigurations.

👉 **Open File:** [`networking-basic.md`](./networking-basic.md)

---

### 🐧 **2. Linux & Bash Essentials**

Command-line skills used by every pentester: privilege handling, shell navigation, automation, and system interaction during exploitation.

👉 **Open File:** [`Linux & Bash-Basics.md`](./Linux%20&%20bash-Basics.md)

---

### 🌐 **3. Web Application Essentials**

Core web knowledge required before attacking applications: HTTP mechanics, virtual hosting, proxies, headers, response codes, and server behavior.

👉 **Open File:** [`Web Application.md`](./Web%20Application.md)

---

### 🛢 **4. SQL Basics for Attackers**

Understanding relational databases, queries, and misconfigurations to prepare for SQL Injection and data-driven vulnerabilities.

👉 **Open File:** [`SQL-BAsics.md`](./SQL-BAsics.md)

---

### ⚡ **5. JavaScript Essentials**

A practical introduction to JS from the perspective of client-side attacks, DOM manipulation, and concepts relevant to XSS and web exploitation.

👉 **Open File:** [`JavaScript-Basics.md`](./JavaScript-Basics.md)

---

### 🐍 **6. Python for Security**

A practical introduction to Python for security automation, HTTP requests, API testing, data parsing, regular expressions, and building custom security tools.

👉 **Open File:** [`Python for Security.md`](./Python%20for%20Security.md)

---
